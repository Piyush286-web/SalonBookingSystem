# Salon Booking Management System

A full-stack Salon Booking Management System that allows customers to book salon services and provides an admin dashboard to manage appointments.

## 🚀 Features

### Customer Side
- Customer registration details
- Salon service selection
- Appointment date and time selection
- Form validation
- Booking confirmation message

### Admin Side
- View all appointments
- View customer details
- View service and price
- Pending / Accepted / Rejected appointment status
- Accept or reject appointments
- WhatsApp customer contact after appointment acceptance

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
